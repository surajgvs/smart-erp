# SmartERP - Modular ERP System (Lite Edition)
A beginner-friendly, modular ERP system built with Java, Spring Boot, MySQL, and React.js. Includes features like Inventory Management, Billing, and REST APIs with CI/CD.

## Overview
SmartERP is a cloud-native, microservices-based ERP system designed to demonstrate full-stack development using Java, Spring Boot, React.js, and modern DevOps practices. It covers core ERP modules like Inventory, Billing, and Reporting with secure, scalable architecture.

## Features
- Modular microservices architecture
- REST + SOAP API support
- Service discovery with Eureka
- API Gateway with Spring Cloud Gateway
- Fault tolerance using Resilience4j
- Frontend built in React.js + TypeScript
- MySQL + MongoDB integration
- Kafka for asynchronous communication
- CI/CD with Jenkins and Docker
- Python utilities for automation

## Tech Stack
- **Backend:** Java 17, Spring Boot, Spring MVC, Spring Security, JPA, Hibernate
- **Frontend:** React.js, React Hooks, Axios, TypeScript
- **Databases:** MySQL, MongoDB
- **DevOps:** Jenkins, Docker, Maven, Gradle, Tomcat
- **Cloud:** AWS (optional), Kafka
- **Tools:** JUnit, Mockito, Cucumber, Swagger
